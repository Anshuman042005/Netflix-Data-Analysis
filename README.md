# Netflix Data Analysis

This project performs exploratory data analysis on the Netflix dataset to uncover trends and insights about content distribution.

## 📌 Objectives
- Analyze the distribution of Movies vs TV Shows
- Identify top countries producing Netflix content
- Understand trends in content addition over the years

## 🚀 Features
- Data cleaning and preprocessing using Pandas
- Analysis of content types (Movies vs TV Shows)
- Country-wise content distribution
- Time-based trend analysis
- Data visualization using Matplotlib

## 🛠 Tech Stack
- Python
- Pandas
- Matplotlib

## 📊 Key Insights
- Movies dominate the Netflix platform
- A few countries contribute majority of the content
- Content addition has increased significantly over recent years

## ▶️ How to Run
1. Download the dataset (netflix_titles.csv)
2. Install required libraries:
   pip install pandas matplotlib
3. Run the script:
   python analysis.py
